# دفتر کار و حسابداری گفت‌وگومحور (Conversational Work Ledger)

یک سیستم حسابداری و دفتر کار شخصی مبتنی بر متن و پیام‌رسان بله (Persian-first) برای ثبت دریافت‌ها، پرداخت‌ها، تعهدات و یادداشت‌های کاری مستقیماً از دل چت و گفت‌وگو. در این سیستم، پیام‌ها ابتدا به پیش‌نویس (Draft) قابل ویرایش تبدیل می‌شوند و رکوردها تنها پس از تأیید صریح کاربر به صورت پایدار ذخیره می‌گردند.

## ویژگی‌های اصلی

- **موتور تحلیل زبان عامیانه و اصطلاحات بازار ایران (`bazaar_parser`):**
  - درک هوشمند عبارات رایج کسبه، بازاریان و کارگران (مانند «کارت کشید»، «دستگاه پوز»، «دخل امروز»، «خرید بار»، «خرج ناهار»، «مساعده»، «تسویه حساب»).
  - پشتیبانی از اعداد متنی و محاوره‌ای فارسی (میلیون، میلیارد، پونصد، دویست و پنجاه هزار و...).
  - استخراج خودکار بابت/توضیحات تراکنش بدون نیاز به سوال و جواب‌های مکرر.
  - اعتبارسنجی دقیق و پرسش رفع ابهام تنها در صورت نامشخص بودن جهت تراکنش یا مقیاس مبلغ (کمتر از ۱۰۰۰ تومان/ریال).
- **چرخه ثبت امن (Draft-First) و تأیید قطعی:**
  - ثبت هیچ رکوردی بدون دستور مستقیم کاربر (`تأیید و ثبت`، `ثبت کن`، `حله`، `درسته`) انجام نمی‌شود.
  - عدم تبدیل خودکار و فرضی مابین واحدهای پولی (تومان و ریال) برای جلوگیری از خطای مالی.
- **بات زنده پیام‌رسان بله (`bale_bot`):**
  - اتصال مستقیم به API رسمی بات بله (`tapi.bale.ai`) با پشتیبانی از Long Polling.
  - ارائه کیبورد شیشه‌ای تعاملی (Inline Keyboard) برای تأیید تک‌کلیکی (Single-tap confirmation)، ویرایش یا لغو پیش‌نویس.
  - ارسال گزارش‌های لحظه‌ای پایش (Shadow Traces) به پنل مدیریت (`Bale-Panel`).
- **پایداری داده‌ها و مدیریت نشست‌ها (`ledger` و `conversation`):**
  - پایگاه داده محلی SQLite برای ذخیره قطعی تراکنش‌ها.
  - محاسبه لحظه‌ای مانده‌حساب (تراز مالی) و فرمت‌بندی اعداد به خط و ارقام فارسی (مانند `۲۵۰٬۰۰۰ تومان`).
  - نگهداری وضعیت نشست‌های چندمرحله‌ای (Multi-turn conversations) با قفل‌های امن همزمانی (Concurrency Locks).
- **حریم خصوصی حداکثری و امنیت:**
  - پاک‌سازی متن خام پیام‌های دریافتی بلافاصله پس از ثبت نهایی یا انصراف از پیش‌نویس.
  - ایزولاسیون کامل داده‌ها بر اساس شناسه بات، پلتفرم و کاربر (`bot_id`, `platform`, `user_id`).

## نقشه پروژه (Project Map)

- `src/bazaar_parser.py` — پردازشگر زبان طبیعی بازار، عبارات بازاری، واحدهای پولی و دکمه‌های تایید.
- `src/bale_bot.py` — کلاینت بات پیام‌رسان بله با کیبوردهای شیشه‌ای و ردیابی لحظه‌ای.
- `src/ledger.py` — موتور دفتر کل SQLite، محاسبه مانده و فرمت‌بندی مبالغ به فارسی.
- `src/conversation.py` — مدیریت سشن‌ها و چرخه حیات پیش‌نویس‌ها در بستر گفت‌وگو.
- `src/p0_core.py` — ماشین وضعیت P0 و قواعد انطباق بدون وابستگی خارجی.
- `tests/` — مجموعه‌ای جامع با ۸۶ آزمون خودکار شامل بررسی‌های پذیرش، حالت‌های خصمانه و شبیه‌سازی پرسوناها.
- `docs/` — مشخصات محصول (PRD)، کاتالوگ سناریوهای واقعی و سوابق معماری.

## راه‌اندازی و استفاده

پروژه به صورت پیش‌فرض با پایتون ۳.۱۱ یا بالاتر و بدون وابستگی اجباری خارجی قابل اجراست.

### ۱. اجرای آزمون‌ها و اعتبارسنجی

برای اجرای کلیه ۸۶ آزمون خودکار:

```bash
# اجرای آزمون‌های واحد و پذیرش
python3 -m unittest discover -s tests -v

# اجرای بازبینی و تولید گزارش شواهد P0
python3 run_p0_review.py
```

### ۲. اجرای بات پیام‌رسان بله

توکن دریافتی از بازوی بات‌ساز بله (`@BotFather`) را در متغیرهای محیطی یا فایل `.env` / `.env.local` قرار دهید:

```env
BALE_BOT_TOKEN="your_bale_bot_token_here"
SHADOW_TRACE_URL="http://localhost:5000/api/traces"  # اختیاری برای ارسال به پنل
```

سپس بات را روشن کنید:

```bash
python3 src/bale_bot.py
```

## نمونه گفت‌وگو در بله

```text
کاربر: کارت کشید ۲۵۰ هزار تومن خرید مانتو مشکی

بات: پیش‌نویس آماده ثبت:
     • نوع: فروش (دریافت)
     • مبلغ: ۲۵۰٬۰۰۰ تومان
     • بابت: خرید مانتو مشکی

     [تأیید و ثبت] [لغو]
```

با فشردن دکمه «تأیید و ثبت» یا ارسال پیام «حله»، تراکنش ثبت شده و مانده صندوق به‌روز می‌شود.
