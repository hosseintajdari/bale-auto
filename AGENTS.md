# Repository agent entrypoint

Before continuing paused work, reporting project status, or creating a new
handoff, read these files in order:

1. `docs/agents/HANDOFF.md` — the single active checkpoint and continuation
   boundary.
2. `docs/agents/README.md` — the maintenance contract for checkpoints,
   handoffs, GitHub tracking, and archival.

Treat phase-specific files elsewhere in `docs/` as durable product evidence or
archived execution records, not as active handoffs, unless
`docs/agents/HANDOFF.md` explicitly delegates the current task to one of them.

Update the active handoff when a material phase completes, work pauses with
unfinished state, the next outcome changes, or an owner decision blocks safe
progress. Keep commands, code, paths, configuration keys, and Git messages in
English.
